Comment ça marche

1. Choisissez un morceau, cherchez-en un avec 🔎 Chercher, ou glissez un fichier MIDI / MusicXML dans la fenêtre. Cliquez sur 🎧 Écouter pour entendre l'air avant de le jouer.

2. Branchez votre écoute :

  • 🎹 MIDI (le plus fiable) : reliez votre piano numérique à l'ordinateur en USB. Les accords et les deux mains sont détectés parfaitement. Comment brancher mon clavier (Casio…) ?
  • 🎤 Micro : pour un piano acoustique. Le micro reconnaît une note à la fois ; sur un accord, une seule note juste suffit. Réglez le seuil de bruit dans ⚙ si des notes fantômes apparaissent.
  • Clavier d'ordinateur (pour tester) : rangée du milieu Q S D F G H J K = Do Ré Mi Fa Sol La Si Do (AZERTY), rangée du haut Z E T Y U = dièses, W/X = octave −/+.

🎙 Reconnaître : faites écouter une musique (ou choisissez un fichier mp3) ; l'appli trouve les notes et prépare la mélodie à jouer.

Sur tablette/téléphone : touchez directement le clavier à l'écran ; branchez un clavier MIDI avec un adaptateur USB-OTG.

3. Appuyez sur ▶ Jouer (ou Espace). Une mesure de décompte est donnée par le métronome.

  • Mode Attente : la partition s'arrête sur chaque note tant que vous ne l'avez pas jouée. Idéal pour déchiffrer.
  • Mode Rythme : la musique avance au tempo ; jouez quand la note touche la ligne. Parfait (±0,10 s), Bien (±0,22 s), sinon Raté.
  • Commencez à 50–70 % du tempo, main par main, puis accélérez.

Couleurs : bleu = main droite, orange = main gauche, vert = réussie, rouge = ratée. Les touches jaunes du clavier indiquent quoi jouer.

Octaves : Do4 = le do du milieu du piano (certaines méthodes françaises l'appellent Do3).

🔎 Chercher une musique

Résultats : fichiers MIDI libres de droits de Wikimedia Commons (beaucoup de classique, de chants traditionnels et d'hymnes). Pour d'autres morceaux, téléchargez un fichier puis glissez-le dans la fenêtre : Mutopia (classique gratuit, MIDI), MuseScore (partitions : « Télécharger → MusicXML » ou « MIDI »), piano-midi.de (piano classique). Les chansons récentes sont protégées par le droit d'auteur : utilisez des fichiers que vous avez le droit de télécharger.

🎙 Reconnaître une musique

Faites écouter un morceau (enceinte, radio, quelqu'un qui chante ou qui joue) : l'appli trouve les notes et vous prépare la mélodie à jouer, avec l'air pour vous guider.

Prêt.

Meilleurs résultats : 10 à 30 secondes, un seul instrument ou une voix nette, peu de bruit autour. Sur une chanson complète (voix + batterie + instruments), la mélodie trouvée est approximative : écoutez-la avec 🎧 et ajustez le tempo. La transcription se fait entièrement sur votre appareil (IA « Basic Pitch » de Spotify, libre). Le titre n'est cherché sur internet que si vous avez mis une clé AudD dans ⚙ Options.

🎚 Choisir les pistes

🎹 Brancher votre clavier Casio (ou autre)

  1. Regardez à l'arrière du clavier. Cherchez une prise marquée USB ou TO HOST : souvent une prise carrée (USB-B, comme une imprimante), parfois micro-USB ou USB-C sur les modèles récents.
  2. Prenez le bon câble : pour une prise carrée, un câble USB-A ↔ USB-B (« câble d'imprimante », quelques euros). Branchez-le directement sur l'ordinateur, sans hub.
    Vous ne voyez que deux prises rondes à 5 broches « MIDI IN / MIDI OUT » ? Il faut alors une interface USB-MIDI (câble avec deux fiches rondes). Si rien ne s'affiche, inversez les deux fiches.
  3. Allumez le clavier. Windows installe tout seul ce qu'il faut (aucun logiciel Casio n'est nécessaire).
  4. Fermez les autres logiciels de musique (Casio Music Space, Chordana, logiciel de MAO…) : sous Windows, un seul programme à la fois peut utiliser le clavier.
  5. Cliquez sur 🔄 Détecter ci-dessous et acceptez l'autorisation « contrôler les appareils MIDI » si le navigateur la demande.
  6. Appuyez sur une touche : la note doit s'afficher dans « Vous jouez ». Le son sort du Casio : vous pouvez baisser le « volume du piano de l'ordi » dans ⚙.
Appareils détectés : —

Toujours rien ? Essayez un autre port USB, éteignez puis rallumez le clavier une fois branché, et vérifiez que le câble transmet bien les données (certains câbles ne font que recharger).
