# 🎹 Piano Cascade

Entraînement au piano : partition qui défile, notes qui tombent vers le clavier,
métronome, écoute de ce que vous jouez (clavier MIDI, micro ou écran tactile),
recherche de musiques libres et reconnaissance / transcription d'une musique.

**▶ Ouvrir l'appli : https://babadu31.github.io/piano-cascade/**

## Installer sur Android (tablette, téléphone)

1. Ouvrez le lien ci-dessus dans **Chrome**.
2. Menu ⋮ → **Installer l'application** (ou le bouton 📲 Installer dans l'appli).
3. Lancez-la depuis l'écran d'accueil, appareil **à l'horizontale**. Elle marche ensuite hors ligne.

Clavier Casio / MIDI : câble USB du clavier + **adaptateur USB-OTG** vers la prise de la tablette.

## Windows

L'exécutable `PianoCascade.exe` est publié dans le dépôt privé de développement.
